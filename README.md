## How this repo is organized

Each top-level section above should become a folder (or a markdown file) with curated content:

- /ai-tools/ - breakdowns, comparisons, top lists, and extension recommendations
- /prompts/ - categorized prompts, prompt engineering tips, and model-specific tips
- /workflows/ - end-to-end AI workflows and automation ideas
- /learning/ - free courses and beginner guides
- /use-cases/ - industry-specific post ideas and business applications
- /career/ - LinkedIn and job seeker content templates
- /news/ - explainer-style short posts and opinion pieces
- /cheatsheets/ - quick references and downloadable notes

Each folder can contain:
- README.md describing the folder and content strategy
- examples/ with ready-to-post templates and sample images
- templates.md listing short, copy-paste-ready LinkedIn post templates

## How to use

1. Pick a topic (e.g., "AI Tools and Comparisons" or "Prompt Engineering").
2. Open the folder and review the templates or short-form content.
3. Copy a template, personalize with your experience or examples, and post on LinkedIn.
4. If you publish a post using these templates, consider opening an issue or PR linking to the post — we can track real-world results and iterate.

## Contribution guidelines

Contributions are welcome! Suggested workflow:

1. Open an issue describing the folder or content you'd like to add or improve.
2. Create a branch and add your markdown files, templates, or examples.
3. Open a pull request and include a short description and a few example posts.

Keep content:
- Original or properly attributed
- Short and actionable (LinkedIn-friendly)
- Organized under the matching folder
