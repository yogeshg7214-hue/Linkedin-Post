# Linkedin-Post - Viral AI Content Vault

A curated collection of LinkedIn viral post patterns based on research of 1000+ high performing posts, with ready to post content and image guidelines.

This repo follows the exact viral infographic pattern found from LinkedIn and Instagram:

```
Attention Hook + Big Promise + Actionable Info + Scan Friendly Cards + Save Worthy Data + Minimal Reading + Branding
```

> New structure: Each category folder has only 2 files - post.txt and image_guidelines.txt

### Viral Pattern Used

From analysis of viral AI images:

1. Hook: Large bold headline with curiosity words like I Accidentally Unlocked, Top 9, Must Know, Stop Doing This. Important keywords highlighted with contrasting color.
2. Value: Teaches one topic - prompts, tools, courses, cheatsheets
3. Layout: Card or grid layout - Title, 1 to 6 cards, footer. Or Left Wrong Right Correct.
4. Typography: Huge headline, short subtitle, bold keywords, bullets not paragraphs
5. Color: White background with one accent color - blue, yellow, orange, green, red. Black text dominant.
6. Density: High info per inch - 9 courses, 27 tips, 80 commands. Goal is save.
7. Visuals: Icons, logos, screenshots, checkmarks, arrows, numbered circles
8. Optimization: Creator name, branding, portrait 3:4 or 4:5 ratio for saves and shares

Overall formula: NUMBER + POWER WORD + TOPIC -> Example: 10 FREE AI COURSES, MUST KNOW AI TERMS, 10 TOOLS THAT SAVE 20 HOURS

### How to use

1. Open any category folder
2. Copy post.txt - it already has integrated ByteBuilders CTA inside, link naturally placed
3. Check image_guidelines.txt - detailed layout based on viral patterns, 3:4 or 4:5, whiteboard or notebook or printed sheet or playbook look, simple clean light themed, official logos and course covers if course post, subtle Subscribe ByteBuilders branding in footer
4. Generate image using guidelines
5. Post on LinkedIn with image

### Image Rules

- Aspect ratio 3:4 or 4:5 portrait
- Simple, clean, light themed
- Whiteboard, notebook page, printed sheet, playbook, research paper, white textured paper, cheat sheet look
- Avoid dark backgrounds, heavy graphics, clutter
- Include provider logos, official course cover if course post
- Add subtle Subscribe ByteBuilders branding in footer
- Minimal reading effort, scan in 5 to 10 seconds, save worthy

### CTA Style

Integrated naturally, not separate. Example:

Customize per post topic for higher clicks.
