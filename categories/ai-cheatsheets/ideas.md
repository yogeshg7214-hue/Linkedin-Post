# AI Cheatsheets

This category is for sharing high-value, actionable cheatsheets for various AI models and tools. These are great for LinkedIn because they provide immediate value and are highly shareable.

## Ideas for Cheatsheets:

### 1. Claude Prompt Engineering Cheatsheet
- **System Prompts**: How to set the persona.
- **XML Tags**: Using `<text>` or `<instructions>` tags to structure data.
- **Thinking Process**: Asking Claude to think step-by-step before answering.
- **Context Window**: How to leverage large context for document analysis.

### 2. ChatGPT Master Cheatsheet
- **Custom Instructions**: Best practices for setting your global preferences.
- **Advanced Data Analysis**: Tips for uploading CSVs and asking for visualizations.
- **Prompt Frameworks**: Using frameworks like ERA (Expectation, Role, Action) or CREATE.
- **GPTs**: How to build and share custom mini-apps.

### 3. AI Tool Comparison Cheatsheet
- A quick table comparing Claude, ChatGPT, and Gemini for different tasks (Writing, Coding, Logic).
